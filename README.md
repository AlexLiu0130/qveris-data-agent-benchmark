# QVeris Data Agent Benchmark

## Goal

Evaluate data-agent behavior across three suites of 100 cases each, using a controlled runtime contract and four benchmark metrics.

## Non-goals

- Choosing an implementation language or framework
- Shipping a production data agent or deployment
- Storing credentials, raw result artifacts, or sensitive data

## Current status

Repository baseline only. Benchmark cases, runtime implementation, evaluators, and reporting are intentionally not yet defined.
